# La Route des Yōkai

Deck builder japonais : un duel de clans où l'on capture des esprits, au rythme du jour et de la nuit. Prototype (Samouraï contre Ninja, face à l'ordinateur).

```
npm install
npm run dev      # développement
npm run build    # dist/index.html, un seul fichier autonome
npm run sim      # équilibrage : l'ordinateur joue contre lui-même
npm run deploy   # build + publication Cloudflare Workers
```
